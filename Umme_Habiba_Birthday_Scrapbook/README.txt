# Umme Habiba — Birthday Scrapbook

A responsive, interactive birthday surprise website made with plain HTML, CSS and JavaScript.

## Run it on Windows
1. Download and extract `Umme_Habiba_Birthday_Scrapbook.zip`.
2. Open the extracted folder.
3. Double-click `index.html` (or right-click → Open with → Chrome).
4. Click **Open your surprise** to enter the scrapbook.

No server, database, React, or paid software is required. An internet connection is used only to load the decorative Google Fonts; the website and photographs work locally.

## Project files
- `index.html` — all scrapbook pages and content
- `style.css` — burgundy/vintage-paper theme, responsive layout and animations
- `script.js` — envelope, page navigation, film strip, photo lightbox, cake candles, confetti and optional generated melody
- `assets/` — the nine supplied photographs

## Personalize the message
Open `index.html` in Notepad or VS Code. Search for `Umme Habiba`, `December 2nd`, or the birthday paragraphs and edit the text.

## Replace photographs
Replace the JPG files in `assets/` while keeping the same filenames (`memory-01.jpg` through `memory-09.jpg`), or update the matching `src` paths in `index.html`.

## Notes
- Music is optional and begins only after the visitor presses the music button. It is a small generated melody, not a copyrighted song.
- The cake surprise is on the final scrapbook page. Press the candle button to blow out the candles and trigger floating confetti.
